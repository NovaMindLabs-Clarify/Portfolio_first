# КОНТУР

Сайт студии ремонта под ключ с калькулятором сметы и личным кабинетом объекта.
Концепт-проект для портфолио (fictional brand) — WOW-анимации + сложный фуллстек + SEO/доступность/скорость + вкус в UI.

## Стек

Next.js 16 App Router, React 19, TypeScript strict, Tailwind v4, Turbopack.
Drizzle + PostgreSQL, Zod, react-hook-form, Better Auth.
GSAP (`@gsap/react`), Motion (`motion/react`), Lenis.

## Дизайн-токены (не отклоняться)

```css
--paper:     #F1F2EF
--graphite:  #1B2430
--grid:      #D7DAD4
--tape:      #F2C230
--blueprint: #3457D5
```

Шрифты: Geologica (display, только 2 начертания на сайт), Golos Text (body), JetBrains Mono (ВСЕ числа — м², рубли, сроки, номера этапов).
Шкала размеров — только `--step--1 … --step-4`.

Easing везде один: `cubic-bezier(0.16, 1, 0.3, 1)`. UI-переходы 200–400мс, сценарные — до 1200мс.

`--tape` используется максимум ОДИН раз на экране. `--blueprint` никогда не для текста — только линии SVG, focus-visible, активный шаг калькулятора.
Никаких градиентов. Тени ≤ 8px blur. Глубина — хайрлайнами `1px solid var(--grid)`.

Подробное описание design-system и чек-лист — в скилле `.claude/skills/kontur-design-system/SKILL.md`, он триггерится автоматически на вёрстку/стили/анимации.

## Правила кода

- Server Components по умолчанию, `'use client'` только там, где нужны хуки/события.
- Все анимации через `useGSAP()` из `@gsap/react`, никогда через голый `useEffect`.
- Анимировать только `transform` и `opacity`, никогда `top/left/width/height`.
- Каждый интерактивный компонент доступен с клавиатуры и имеет ARIA. Результаты расчётов — `aria-live="polite"`.
- Каждая анимация обязана обрабатывать `prefers-reduced-motion: reduce` — не отключение, а альтернативная подача.
- Одна Zod-схема на клиент и сервер, импортируется из `lib/schemas`.
- Без `any`. Без `console.log` в коммитах.

## Формула сметы

Ядро проекта, живёт в `lib/estimate.ts` как чистая функция, покрыта тестами Vitest.

```
Смета = Площадь × Ставка × K_санузлы × K_срочность × K_планировка + Материалы

Ставка (₽/м², рынок Санкт-Петербурга, 2026 — по прайсам ремонтных студий СПб):
  косметический  6 500–9 500   (точка расчёта 8 000)
  капитальный    10 500–15 000 (точка расчёта 12 400)
  дизайнерский   14 000–22 000 (точка расчёта 16 500; премиальные дизайн-студии SPb уходят и выше, до 35 000+, это вне типового чека проекта)
K_санузлы    = 1 + 0.08 × (кол-во санузлов − 1)
K_срочность  = 1.0 обычный / 1.15 ускоренный / 1.3 срочный
K_планировка = 1.0 без изменений / 1.12 перенос перегородок / 1.25 перенос мокрых зон
Материалы    = Площадь × (3000 / 6000 / 12000) по классу

Вилка: −8% … +12% от расчёта
```

Дисклеймер обязателен: «Предварительный расчёт. Точная смета — после замера».

## Чего не делать

## Структура страниц

```
/                        Главная (лендинг + калькулятор)
/objects                 Каталог объектов
/objects/[slug]          Кейс объекта (SSG + ISR)
/services/[slug]         SEO-страницы услуг
/calculator              Калькулятор на отдельном URL
/calculator?c=<hash>     Расшаренный расчёт
/about                   Команда, лицензии, СРО
/cabinet                 Личный кабинет клиента (auth)
/cabinet/[objectId]      Дашборд объекта
/demo                    Демо-вход в кабинет без регистрации (критично для портфолио)
/api/*                   Route handlers
```
