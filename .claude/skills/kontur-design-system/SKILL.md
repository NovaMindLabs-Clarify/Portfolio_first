# Дизайн-система «КОНТУР»

Правила ниже фиксированы для всего проекта. Они существуют, чтобы сайт не расползался в типовой AI-лендинг: узкая палитра, два шрифта на роли, один акцент на экран. Отклонение от токена — не стилистическая вольность, а баг.

## Токены

```
--paper      #F1F2EF
--graphite   #1B2430
--grid       #D7DAD4
--tape       #F2C230
--blueprint  #3457D5
```

- `--tape` — максимум **один раз на экране**. Это акцент-маркер, а не цвет для декора; если на экране уже есть `--tape`, следующий акцентный элемент красится иначе (обычно `--blueprint` для фона/обводки, не текста).
- `--blueprint` **никогда** не используется для текста — только фон, обводка, графика, линии.
- Никаких градиентов нигде.
- Тени — блюр не больше 8px, и только для приподнятых интерактивных элементов, не для украшения.
- Глубина/разделение — хайрлайнами `1px solid var(--grid)`, не тенями и не более толстыми бордерами.

Перед сдачей вёрстки проверь: не появился ли второй `--tape` на экране, не попал ли `--blueprint` в `color`/`text-*`, нет ли `background: linear-gradient`/`radial-gradient` и box-shadow с blur > 8px.

## Типографика

- **Geologica** — заголовки. На весь сайт только два начертания (например Regular + SemiBold) — не вводи третье ради одного заголовка.
- **Golos Text** — весь обычный текст (параграфы, лейблы, UI-текст).
- **JetBrains Mono** — ВСЕ числа без исключения: площадь (м²), рубли, сроки, номера этапов, выноски-аннотации, счётчики. Число никогда не набирается основным шрифтом, даже инлайново внутри предложения на Golos Text — оборачивай число в моноширинный спан.
- Шкала размеров — только переменные `--step--1 … --step-4`. Если нужного размера нет в шкале, это сигнал пересмотреть композицию, а не завести `--step-5` на месте.

## Движение

- Единый easing на весь проект: `cubic-bezier(0.16, 1, 0.3, 1)`. Не подбирай другой easing "на глаз" для конкретной анимации.
- Длительности: UI-переходы (ховеры, открытие/закрытие, переключение состояний) — 200–400мс. Сценарные анимации (появление секций, повествовательные переходы) — до 1200мс.
- GSAP подключается только через `useGSAP()` из `@gsap/react`. Никогда через голый `useEffect` — это ломает cleanup и переиспользование контекста анимации между ремаунтами.
- Анимировать только `transform` и `opacity`. Никогда `top`/`left`/`width`/`height`/другие layout-свойства — это триггерит reflow и рушит INP/CLS бюджеты ниже.
- `will-change` ставится непосредственно перед анимацией и снимается сразу после её завершения — не держится в стилях постоянно.
- Каждая анимация обязана иметь ветку `prefers-reduced-motion: reduce`. Это не «выключить анимацию», а **альтернативная подача**: мгновенное появление конечного состояния + fade 200мс. Пользователь должен увидеть контент, просто без движения.

## Бюджеты производительности

Проверяй перед тем, как считать фронтенд-задачу выполненной:

- LCP < 1600мс
- INP < 120мс
- CLS < 0.03
- JS first-load < 120КБ gzip
- Lighthouse: Performance 95+, Accessibility 100

Если правка добавляет тяжёлую анимацию или библиотеку — прикинь, не пробивает ли она эти бюджеты, до того как считать работу готовой.

## Доступность

- Контраст текста — минимум 4.5:1.
- На фоне `--tape` текст только `--graphite` (это единственная разрешённая комбинация текста на этом фоне).
- `:focus-visible` — рамка 2px `var(--blueprint)` с отступом (outline-offset). `outline: none` без замены запрещён в любом виде.
- Тач-таргеты — не меньше 44×44px.
- Кастомные контролы (слайдер площади, before/after-перетаскивание, многошаговая форма) обязаны иметь полную клавиатурную навигацию и корректные ARIA-роли/атрибуты — это ручные паттерны, статический линтер их не поймает.
- Результат расчёта (калькулятор, итоговая цена/срок) — выводится в контейнере с `aria-live="polite"`, чтобы скринридер озвучивал обновление без повторного фокуса.

## Чек-лист перед сдачей

- [ ] `--tape` встречается не больше одного раза на экране
- [ ] `--blueprint` не используется как цвет текста
- [ ] Нет градиентов, тени ≤ 8px blur, разделители — хайрлайны `--grid`
- [ ] Заголовки — Geologica (не больше 2 начертаний), текст — Golos Text, все числа — JetBrains Mono
- [ ] Размеры только из `--step--1…--step-4`
- [ ] Все анимации — `transform`/`opacity`, единый easing, есть ветка `prefers-reduced-motion`
- [ ] GSAP через `useGSAP()`, не через `useEffect`
- [ ] Фокус видим (`:focus-visible`, 2px `--blueprint`), контраст 4.5:1, тач-таргеты 44px+
- [ ] Кастомные контролы доступны с клавиатуры и озвучиваются скринридером
